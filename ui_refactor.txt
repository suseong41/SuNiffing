 [B-4] 명령 비동기화 (ANR 방지)                         [Lv2 검증]
--------------------------------------------------------------------------------
 파일 : mainwindow.cpp (onStartButton / onStopButton)
 핵심 : UI 스레드 동기 대기(waitForFinished) 3곳 -> QProcess::finished 시그널+람다
 변경 :
   - onStartButton:
       * setup "su -c ..." 의 waitForFinished(3000) 제거 -> 비동기 실행
       * finished 핸들러에서 채널 홉핑 타이머 + runDaemon() 시작
       * 진행 중 startButton 비활성, errorOccurred(FailedToStart) 시 UI 복구
   - onStopButton:
       * daemonProcess->waitForFinished(2000) 제거 (terminate 만 호출)
       * cleanup "su -c ..." 의 waitForFinished(5000) 제거 -> 비동기 실행
       * finished 핸들러에서 devIn/stopButton 복구
       * isRunning=false 를 함수 진입부로 이동 (재진입 방지)
       => onStop 최악 7초 블록 -> 0초
   - 임시 QProcess: this 부모로 힙 할당 + deleteLater() 정리
 유지(이번 범위 아님) :
   - nextChannel(): 이미 QProcess::startDetached (비블로킹). 0.5s 마다 su 신규
     프로세스 생성하는 자원 churn 은 별도 재검토 대상.
 의도된 동작 변화 (추적 필요) :
   1. UI 블록 제거 -> ANR 해소
   2. 데몬 시작이 "setup su 실제 종료 후"로 변경 (기존 3초 캡 제거).
      su 가 무한 정지하면 데몬 미시작 + startButton 비활성 유지 (극단 엣지).
      필요시 안전 타임아웃(QTimer) 추가 가능.
   3. 종료 시 데몬 종료를 기다린 뒤 wifi 복구하던 2초 대기 제거 -> 병렬 실행.
      (기존 대기는 best-effort)
 검증 :
   - g++ -std=c++20 -fsyntax-only (Qt6 frameworks) exit=0
   - Lv3(런타임) 미실시
